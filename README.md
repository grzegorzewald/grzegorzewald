# Hi, I'm Grzegorz Ewald

**Data pipelines · Python · IoT**

I'm based in Poland and work at Keyloop. My public projects span recovering
events in real-time data pipelines and experimenting with connected hardware.

## Selected projects

### [SnowplowRecovery](https://github.com/grzegorzewald/SnowplowRecovery)

A recovery utility for Snowplow real-time pipelines. It reads backup records
from Amazon S3 or a local file and can send them to an Amazon Kinesis stream
or emit base64-encoded records to standard output.

**Technologies:** Python, Snowplow, Amazon S3, Amazon Kinesis.

### [ESP8266 IoT thermometer](https://github.com/grzegorzewald/ESP8266-iot-thermometer)

A NodeMCU-based thermometer built with Lua on the ESP8266—a small hardware
experiment alongside my data pipeline work.

**Technologies:** Lua, ESP8266, NodeMCU.
